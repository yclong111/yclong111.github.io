# yicheng long — personal site

Personal/portfolio site: a single continuous-scroll page built around the
throughline of growing up split between Lower Merion, PA and Shanghai, China,
moving into education, experience, and how to get in touch.

Plain HTML/CSS/JS, no build step, no dependencies. Deployed via GitHub Pages
from the `main` branch at https://yclong111.github.io.

## Local preview

```
python3 -m http.server 8765
```

then open http://localhost:8765.

## Structure

```
index.html            page content
assets/css/style.css  styling, palette, layout
assets/js/main.js     scroll-reveal + timeline-rail behavior
```
